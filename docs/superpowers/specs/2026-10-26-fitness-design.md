# Muscular Definition

A mobile-friendly personal gym tracker hosted on GitHub Pages in a public repository, as explicitly requested. Use plain HTML, CSS and JavaScript, with no server, accounts, analytics or external dependencies. Personal entries remain in browser storage; JSON export/import provides backup and manual transfer.

Preserve the handover's entire Monday–Thursday programme, optional Friday and weekend rest. Do not use the older PDF's ab wheel. Separate warm-ups from working sets and never treat trial loads as verified capabilities. Log sets, reps, RIR and completion by session date; show progression only from completed, technically sound sets.

Use an understated cream and forest-green dashboard, responsive navigation, large gym-friendly controls and clear empty states. Overview links to workouts, nutrition, progress and the four-phase roadmap. Nutrition recalculates from an adult profile using Mifflin–St Jeor, an explicit activity multiplier and a selectable moderate deficit, maintenance or small surplus. Protein defaults to the programme's 2.05 g/kg and fat to 0.9 g/kg; carbohydrates use remaining calories. Unknown age must be entered before personalized estimates appear. Explain estimates and trend-based adjustment. Allow calorie override and adjustable whey intake.

Alternatives: a hosted server with account sync offers convenience but adds account and storage complexity; a static browser-local tracker fits free GitHub Pages and the user's instruction to proceed. The latter is the implementation choice. Do not publish original private attachments, personal progress records or credentials.

Validation: pure-function tests for nutrition, validation, dates, overload and backup schema; browser checks for navigation, profile changes, logs, persistence and responsive layout; confirm GitHub Pages deployment.
