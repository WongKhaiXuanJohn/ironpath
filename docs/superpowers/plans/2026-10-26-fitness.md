# Fitness Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task.

**Goal:** Publish the confirmed programme as a functional personal tracker on GitHub Pages.
**Architecture:** Static site with pure domain functions, immutable programme data and local browser state. No uploads of personal entries.
**Tech Stack:** HTML, CSS, native JavaScript modules, Node test runner.
**Spec:** docs/superpowers/specs/2026-10-26-fitness-design.md

## Global Constraints
- Monday–Thursday compulsory; Friday optional; weekends off.
- No floor ab exercises; Monday Captain's Chair Knee Raise.
- Warm-ups excluded from working-set totals; trial loads unverified.
- Age not known; require it for calculated estimates.
- Public source, browser-local records, free GitHub Pages.

## Review Focus
- Blank and extreme numeric input: reject without overwriting saved state.
- Invalid backup: reject atomically; never interpret imported text as HTML.
- Missing logs: show empty states instead of invented progress.
- Partial sets and poor form: do not recommend increased load.
- Local dates and future/past programme dates: stable phase boundaries.

### Task 1: Domain and programme
Files: assets/core.js, assets/programme.js, tests/core.test.mjs.
Interfaces: calculateNutrition(profile), nextLoad(exercise, sets), programmeWeek(start,date), validateBackup(data).
- [ ] Write tests asserting actual macro arithmetic, profile sensitivity, invalid inputs, warm-up exclusion, progression and date boundaries; run and observe failure.
- [ ] Implement pure functions and exact programme data; run npm test and verify all pass.

### Task 2: Complete interface
Files: index.html, assets/style.css, assets/app.js, assets/icon.svg.
Consumes Task 1 exports; produces a responsive dashboard and validated forms for all persistence operations.
- [ ] Implement overview, dated workout logging, nutrition, progress, roadmap and profile/backups.
- [ ] Verify profile recalculation, set completion, reload persistence, charts, all navigation and mobile sizing in browser.

### Task 3: Publish
Files: README.md, .gitignore, .nojekyll.
- [ ] Run complete tests and JavaScript syntax checks; review published files for personal data and secrets.
- [ ] Create public repository, push verified source and enable Pages from main root.
